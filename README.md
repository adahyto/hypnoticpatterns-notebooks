# Learn Python with Hypnotic Patterns

Notebooks of the free Python course at https://hypnoticpatterns.doner.cloud/learn: each lesson builds one pattern of the YouTube channel [Hypnotic Patterns](https://www.youtube.com/@HypnoticPatternsAudio) in a short script, line by line, with exercises. Open one in Google Colab and run it in your browser, nothing to install.
